## 二、JSON 格式（必须和 PROTOCOL.md 完全一致）

```json
{
  "type": "sensor",
  "dev": "mcu01",
  "msg_id": "mcu01-report-0001",
  "ts": 1754557200,
  "body": {
    "data": {
      "temp": 25.6,
      "humi": 60.1,
      "light": 320,
      "ir": 0
    }
  }
}
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| `type` | 是 | 固定 `"sensor"` |
| `dev` | 是 | 设备 ID，**必须和 topic 里的 mcu01 一致** |
| `msg_id` | 否 | 消息唯一 ID（调试用） |
| `ts` | 否 | Unix 时间戳（秒），没有 RTC 可传 0 |
| `body.data.temp` | 否 | 温度 |
| `body.data.humi` | 否 | 湿度 |
| `body.data.light` | 否 | 光照 |
| `body.data.ir` | 否 | 红外 0/1 |

> 没有的字段可以不传（网关会判断），但**不能传空字符串**。

## 三、ESP8266 示例代码（Arduino IDE + PubSubClient）

### 依赖库安装

Arduino IDE → 库管理器 → 搜索安装：
- `PubSubClient` by Nick O'Leary

### 完整代码

```cpp
#include <ESP8266WiFi.h>
#include <PubSubClient.h>

// ========== 配置区（改成你们的值）==========
const char* WIFI_SSID = "你们的WiFi名";
const char* WIFI_PASS = "你们的WiFi密码";
const char* MQTT_HOST = "192.168.5.80";   // RK3568 板子 IP
const int   MQTT_PORT = 1883;
const char* DEV_ID    = "mcu01";          // 设备 ID
const char* MQTT_TOPIC_REPORT = "iotgw/v1/dev/mcu01/report";
const char* MQTT_TOPIC_CMD    = "iotgw/v1/dev/mcu01/cmd";   // 以后订阅命令用
// ==========================================

WiFiClient espClient;
PubSubClient mqtt(espClient);

// ---------- 传感器读取（换成你的实际外设）----------
float read_temp()  { return 25.6; }   // 改成 DHT11 读取
float read_humi()  { return 60.1; }   // 改成 DHT11 读取
float read_light() { return 320; }    // 改成光敏 ADC 读取
int   read_ir()    { return 0; }      // 改成 HC-SR501 读取

// ---------- 拼 JSON ----------
String build_report_json() {
  String json = "{";
  json += "\"type\":\"sensor\",";
  json += "\"dev\":\"" + String(DEV_ID) + "\",";
  json += "\"msg_id\":\"r" + String(millis()) + "\",";
  json += "\"ts\":0,";
  json += "\"body\":{\"data\":{";
  json += "\"temp\":" + String(read_temp(), 1) + ",";
  json += "\"humi\":" + String(read_humi(), 1) + ",";
  json += "\"light\":" + String(read_light()) + ",";
  json += "\"ir\":" + String(read_ir());
  json += "}}}";
  return json;
}

// ---------- MQTT 断线重连 ----------
void reconnect() {
  while (!mqtt.connected()) {
    Serial.print("正在连接 MQTT...");
    if (mqtt.connect("esp8266-mcu01")) {   // client_id 不要和网关重名!
      Serial.println(" 已连接");
      mqtt.subscribe(MQTT_TOPIC_CMD);      // 订阅命令 topic (以后用)
    } else {
      Serial.print(" 失败, 状态码: ");
      Serial.println(mqtt.state());
      delay(3000);
    }
  }
}

// ---------- 命令回调 (以后网关下发控制时用) ----------
void on_cmd(char* topic, byte* payload, unsigned int len) {
  Serial.print("收到命令: ");
  Serial.println((char*)payload);
  // TODO: 解析命令, 控制 LED/电机/舵机/蜂鸣器
}

void setup() {
  Serial.begin(115200);

  // 1. 连 WiFi (只支持 2.4G!)
  WiFi.begin(WIFI_SSID, WIFI_PASS);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("\nWiFi 已连接");
  Serial.print("IP: ");
  Serial.println(WiFi.localIP());

  // 2. 配置 MQTT
  mqtt.setServer(MQTT_HOST, MQTT_PORT);
  mqtt.setCallback(on_cmd);
}

void loop() {
  // 3. 保持 MQTT 连接
  if (!mqtt.connected()) {
    reconnect();
  }
  mqtt.loop();   // 必须每轮调用, 否则心跳断了被踢

  // 4. 周期上报
  String json = build_report_json();
  bool ok = mqtt.publish(MQTT_TOPIC_REPORT, json.c_str());
  Serial.print("发布: ");
  Serial.println(ok ? "成功" : "失败");

  delay(5000);   // 5 秒发一次
}
```

### 关键点

1. **WiFi 必须 2.4G**——连不上 5G 路由器是最大坑
2. `mqtt.connect("esp8266-mcu01")` 的 **client_id 不能和网关重名**（网关是 `edgegw-dev`）
3. **`mqtt.loop()` 每轮都要调用**——不调会被 broker 踢下线
4. `dev` 字段（`mcu01`）和 topic 里的 `mcu01` **必须一致**
5. 先不接外设也能测：用默认返回值 `read_temp()` 直接发

## 五、常见问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| ESP8266 连不上 WiFi | 路由器是 5G | 换 2.4G 频段 / 手机热点 |
| MQTT 连接失败 状态码 -2 | broker 没监听 0.0.0.0 | 板子上 `netstat -ltn | grep 1883` 应显示 0.0.0.0:1883 |
| MQTT 连接失败 状态码 -4 | client_id 冲突 | 换 client_id |
| 能连上但板子收不到 | topic 写错 | 对照本文档 Topic |
| 板子收到但"解析失败" | JSON 格式错 | 少引号/多逗号, 对照第二节格式 |
| 板子重启后连不上 | IP 变了 | 板子设静态 IP 192.168.5.80 |
